# Flight Delay Prediction Dashboard (modeled data)

**Dashboard and analysis scripts on a modeled (simulated) dataset.**

## In one minute

A dashboard answering three questions a travel-tech PM might be asked about delay risk: which routes delay most, how airlines differ, and how season and time of day shape delay risk. The data is not real: it is 8,000 flights generated by a script from documented parameters, with fictional airline names and real Indian city-pair routes. Delay minutes are drawn from a gamma distribution. The page says the first pass gave a 48.9% on-time rate, so the parameters were re-tuned to a plausible range.

## What is real, modeled or not verified

| Topic | Status |
|---|---|
| Modeled data | Every number in the dashboard comes from the generator's chosen parameters. None of it measures a real airline or route. Patterns such as winter fog and monsoon effects were put in deliberately. |
| Parameters were tuned | The generator was re-tuned after the first pass looked implausible (per the page). The results therefore reflect the author's assumptions. |
| Scripts not re-run | generate_dataset.py and analyze.py were not re-run when this repo was set up. |
